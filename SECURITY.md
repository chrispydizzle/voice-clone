# Security Policy

## Reporting a vulnerability

Use the repository's **Security** tab and **Report a vulnerability** to submit
details privately. If private vulnerability reporting is unavailable, open a
minimal issue requesting a private contact channel; do not include exploit
details, recordings, voice profiles, credentials, or personal information.

Please include the affected version, reproduction steps, impact, and any
suggested mitigation. Security reports will be acknowledged as availability
permits.

## Scope

The application is intended to bind to localhost. Exposing the Gradio service
to a network or the public internet is unsupported and increases the risk of
unauthorized voice generation and access to locally saved profiles.
